# ice-study 🧊

**氷が溶けるまで勉強する** — YouTubeの「氷が溶けるまで勉強する」を再現したタイマーです。

🧊 **公開ページ: https://n494n0tk.github.io/ice-study/**

瓶に入った氷が少しずつ溶けて、水になっていきます。氷がぜんぶ溶けたら、きょうの勉強はおしまい。

## 使い方

`index.html` をブラウザで開くだけです(ビルド不要・依存ライブラリなし)。

```
python3 -m http.server   # ローカルサーバーで開く場合(通知機能にはこちら推奨)
```

GitHub Pages にそのまま置いても動きます(Settings → Pages → ブランチを選択)。

## ルール

- **氷1個 = 5分**。設定した時間が長いほど、大きな瓶にたくさんの氷が入ります(例: 25分 → 5個、60分 → 12個)
- 氷は上の段から1個ずつ順番に溶けていき、溶けた分だけ水位が上がります
- **タブを閉じても氷は実時間で溶け続けます**(本物の氷は待ってくれないので)。止めたいときは「冷凍庫に戻す」

## 機能

- 一時停止(冷凍庫に戻す)・再開・リセット
- 残り時間の表示/非表示(氷だけ見て頑張るモード)
- 雨の音(Web Audioで合成。音声ファイルなし)+ 音量調整
- 終了時のチャイムとデスクトップ通知(通知は https / localhost のみ)
- リロードしてもセッションは継続(localStorage)

## デバッグ

URLに `?speed=100` を付けると時間が100倍速で進みます(例: 25分セッションを15秒で確認)。

```
http://localhost:8000/index.html?speed=100
```
